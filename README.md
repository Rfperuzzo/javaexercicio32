# Maior, Menor, Soma e Média

Programa desenvolvido em **Java** para praticar estruturas de repetição, condicionais e operações matemáticas.

## 📌 Objetivo

O programa solicita uma quantidade de números ao usuário e, após a entrada dos valores, apresenta:

- Menor número informado;
- Maior número informado;
- Soma de todos os números;
- Média dos números.

## ⚙️ Funcionamento

Primeiro, o usuário informa quantos números deseja inserir.

Em seguida, o programa utiliza um laço `for` para receber cada número e realizar os cálculos necessários.

Durante a execução:

- `soma` armazena a soma dos valores;
- `meV` armazena o menor valor;
- `maV` armazena o maior valor;
- `media` armazena a média dos números.

O primeiro número digitado é utilizado para inicializar o menor e o maior valor.

## 💻 Tecnologias utilizadas

- Java
- Scanner
- Estrutura de repetição `for`
- Estruturas condicionais `if` e `else`
